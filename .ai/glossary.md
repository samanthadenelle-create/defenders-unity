# Tooling glossary

- Work order: validated objective, requirements, scope, implementation steps and acceptance checks.
- Worker: a model proposing bounded tool actions.
- Reasoner: a model planning work or reviewing difficult failures.
- RCA: a failure package with the request, original plan, diff and observed failures.
- DONE: configured checks passed; a diff is ready for review, not merged.
- FAIL: work stopped; retained diagnostics and patches are available.
